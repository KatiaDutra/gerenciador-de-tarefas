# Gerenciador de Tarefas

Aplicação web para cadastrar, organizar e acompanhar tarefas do dia a dia, desenvolvida como exercício do curso de Desenvolvimento Front-end (Programa Bolsa Futuro Digital).

# Funcionalidades

- Cadastro de tarefas (descrição, categoria, prioridade e prazo)
- Listagem dinâmica das tarefas cadastradas
- Marcar/desmarcar tarefa como concluída
- Exclusão de tarefas, com confirmação
- Filtro por situação (todas / pendentes / concluídas) e por categoria
- Cadastro de novas categorias pelo usuário
- Indicadores de total, pendentes e concluídas
- Dados salvos no localStorage do navegador

# Tecnologias

- HTML5
- CSS3
- JavaScript (puro, sem frameworks)
